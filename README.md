# GisFind

Поиск клиентов через 2ГИС. Собирает организации по нише и городу, вытаскивает
телефоны, WhatsApp, Instagram и почту, отмечает тех, у кого нет сайта, и готовит
персональное первое сообщение под каждый бизнес.

Рассылки нет. Кнопка открывает WhatsApp с готовым текстом, отправляет человек.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
python run.py
```

Дальше http://127.0.0.1:8000, регистрация, первый поиск.

`playwright install chromium` нужен только для запасного режима, обычный сбор
идёт без браузера.

## Настройки

Все параметры читаются из `.env`, образец в `.env.example`.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `SECRET_KEY` | dev-ключ | Подпись cookie сессии. Заменить перед публикацией. |
| `ANTHROPIC_API_KEY` | пусто | Генерация сообщений через Claude. Без ключа работает встроенный генератор. |
| `CONCURRENCY` | 12 | Сколько страниц тянуть одновременно. |
| `DB_URL` | sqlite в `data/` | Строка подключения к базе. |

## Как устроен сбор

Публичный ключ веб-версии 2ГИС отдаёт 403 на `/3.0/items` и `/3.0/items/byid`,
поэтому REST API отпадает. Зато страницы приходят server-side rendered: и выдача,
и карточка фирмы содержат `initialState` со всеми данными.

Два запроса на организацию:

1. `/search/<ниша>[/page/N]` — список организаций и общее число в нише.
2. `/firm/<org_id>` — контакты из `contact_groups`, уже типизированные:
   `phone`, `website`, `email`, `instagram`, `whatsapp`, `telegram`.

Браузер нужен только как запасной путь: если 2ГИС перестанет отдавать страницы
обычному клиенту, сбор сам переключится на Playwright. Первый неудачный запрос
служит признаком блокировки, разовые сбои сети лечатся повтором.

Скорость: около 0.4 секунды на лид, 10 организаций без сайта примерно за 4 секунды.

## Чего нет

- Приём платежей. Кнопки на странице тарифов переключают план без оплаты.
- Очередь задач. Сбор идёт в потоке внутри процесса, при перезапуске
  незавершённый сбор остаётся в статусе `running`.
- Дедупликация между сборами. Одна организация в двух сборах — две записи.
- Ротация прокси. Если 2ГИС отдаст капчу, сбор завершится ошибкой.

## Правовая сторона

Собираются контакты организаций, опубликованные ими в 2ГИС. У 2ГИС есть
пользовательское соглашение, ограничивающее автоматизированный сбор, а рассылка
коммерческих предложений регулируется законом «О рекламе» РК. Отправляйте вручную,
не больше 20–30 первых сообщений в день с одного номера, и прекращайте после отказа.
